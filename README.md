# Personal Portfolio Website

This repository contains the source code for deployment of my personal portfolio website.<br>

Visit: https://adeshkumarml.vercel.app/<br>

## Tech Stack
- React
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript (ES6+)
- Light / Dark Theme
- Responsive Design
- English / Japanese Localization

## Features
- Responsive portfolio interface
- Bilingual EN / JP support
- Smooth section navigation
- Theme switching
- Animated transitions and subtle motion
- Project showcase and contact links
- Resume download support
